# 醉里逢秋

这是一个可直接打开的中国古典诗歌互文可视化网页。它从李白、杜甫诗句关系表恢复全诗，支持星图浏览、关键词联想、左右全诗对读与相似度筛选。

## 打开方式

直接双击 `index.html` 即可。页面不依赖网络或本地服务器，因为预处理后的数据和图片都在项目目录中。

## 功能

- 双星图：每首诗为一个光点，李白居左、杜甫居右，诗对相似度决定连线亮度。
- 相似度门槛：默认显示 80 分以上关系，可调至 70—90 分。
- 关键词联想：仅检索出现在互文关系中的诗句，并显示最相近的上下文。
- 双卷对读：点击诗句后展开两首全诗，高亮匹配句并显示对应墨线。
- 关系细目：查看当前诗对的全部匹配句、句序与相似度。

## 重新生成数据

原始数据位于 `李杜/李杜/`。修改 CSV 后，在此目录运行：

```powershell
node .\scripts\preprocess.js
```

脚本会：

1. 读取 `李白.csv`、`杜甫.csv` 和 `李白-杜甫.csv`；
2. 按诗歌 ID 聚合完整诗作，按诗句 ID 恢复句序；
3. 校验所有关系句都能在完整诗中找回；
4. 生成浏览器可直接加载的 `assets/js/data.js`。

当前生成结果包含 23,448 条诗句关系、1,084 首李白诗和 1,462 首杜甫诗。

## 解释限度

页面将结果表述为“相似关系”“候选互文”或“文本呼应”。相似度不等于已经证成的引用、化用或影响关系，最终判断仍应回到原诗、异文和文学史材料。
